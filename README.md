# Memory Game
Интерактивная игра на поиск одинаковых карточек.

## О проекте
Memory Game — браузерная игра, в которой игрок должен находить пары одинаковых карточек за минимальное количество ходов.

## Функционал
- Перемешивание карточек при старте игры
- Подсчет ходов
- Подсчет совпадений
- Таблица лидеров (LocalStorage)
- Модальные окна (Победное и Таблица лидеров)
- Начало новой игры
- Адаптивный интерфейс

## Технологии
- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage
- Json

## Запуск проекта
1. Клонировать репозиторий:

```bash
git clone https://github.com/Holanad/memory-game.git
```

2. Перейти в папку проекта:

```bash
cd memory-game
```

3. Открыть `index.html` в браузере.

## Правила игры
1. Нажмите на карточку для открытия.
2. Откройте вторую карточку.
3. Если изображения совпали — пара остается открытой.
4. Если нет — карточки закрываются спустя 800ms.
5. Игра завершается после нахождения всех пар.

## Таблица лидеров
Результаты сохраняются в LocalStorage браузера.

Сохраняются:
- Количество ходов;
- Дата прохождения.
